# Nuran Farhana Prova — Portfolio

A responsive React + Vite portfolio website.

## Run locally
1. Install Node.js (LTS): https://nodejs.org/
2. Extract this project folder.
3. Open a terminal in the project folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL shown in the terminal.

## Build
Run `npm run build`. The production website will be generated in `dist/`.

## Deploy free with Vercel
1. Push this project to a GitHub repository.
2. Sign in to https://vercel.com/ with GitHub.
3. Click Add New → Project.
4. Import this repository.
5. Keep Framework Preset as Vite.
6. Build Command: `npm run build`
7. Output Directory: `dist`
8. Click Deploy.

## Before publishing
- Confirm the LinkedIn URL and update it in `src/App.jsx` if needed.
- Replace the project GitHub profile links with exact repository URLs when available.
- Add a profile photo if desired; the current hero uses a typographic monogram.
- The CV PDF is stored in `public/` and linked from the hero button.
